# FOR YOU — متجر الهدايا (المرحلة 1.5)

واجهة المتجر + لوحات المدير والأدمن والتحضير + صفحات الإهداء الإلكتروني. خادم Node صغير **بدون أي مكتبات**.

## ما الذي يُحفظ وأين؟
| البيانات | أين تُحفظ |
|---|---|
| المنتجات والطلبات والموظفين والصور والإعدادات | **متصفح كل جهاز** (IndexedDB). غير مشتركة بين الأجهزة |
| صفحات الإهداء المنشورة | **على الخادم** (ملف JSON) فتفتح من أي جهاز |

لذلك: النظام يشتغل كاملاً على جهاز المدير. لو دخل الأدمن من جهاز ثاني يشوف نظاماً فارغاً. التشغيل المشترك الحقيقي هو المرحلة 2 (`docs/NEXT_PROMPT.md`).
استعملي **نسخ واستيراد** من لوحة المدير لأخذ نسخة كاملة أو نقل البيانات لجهاز آخر.

## التشغيل محلياً
```
npm start
```
ثم http://localhost:3000 (لا يحتاج npm install).

## الرفع على GitHub
```
git init
git add .
git commit -m "FOR YOU"
git branch -M main
git remote add origin https://github.com/USERNAME/foryou-store.git
git push -u origin main
```
أنشئي المستودع فارغاً وبشكل **Private**. لا ترفعي ملفات النسخ الاحتياطية (.json) ولا `.env`.

## النشر على Railway
1. railway.app ← New Project ← Deploy from GitHub repo.
2. Variables ← أضيفي `PUBLISH_KEY` بقيمة كلمة سر طويلة من اختيارج.
3. (مهم للإهداءات) Settings ← Volumes ← New Volume، Mount path: `/data`. بدونه تُمسح الإهداءات المنشورة عند كل إعادة نشر.
4. Settings ← Networking ← Generate Domain.
5. تأكدي: `https://رابطك/api/health` يرجع `{"ok":true}`.
6. ادخلي لوحة المدير ← الإعدادات ← «ربط الإهداءات بالخادم» ← اكتبي نفس `PUBLISH_KEY` ← حفظ واختبار. يطلع «المفتاح صحيح ✓».
7. أنشئي إهداء: يُنشر تلقائياً ويظهر «على الخادم ✓»، وينسخ الرابط ويفتح من أي جهاز.

## متغيرات البيئة
`PUBLISH_KEY` (للنشر)، `DATA_DIR` (اختياري)، `PORT` (تلقائي).
